# Changelog

## 0.1.0-rc.1 - 2026-09-19

First private release candidate.

- Shared CLI/headless coding-agent runtime.
- Durable SQLite session, event, artifact, cancellation, and recovery records.
- File, search, edit, Shell, background-job, permission, and workspace tools.
- macOS Seatbelt confinement for Shell and background processes.
- OpenAI-compatible streaming provider with DeepSeek real-provider validation.
- Workspace instructions, declarative project skills, and context compaction.
- Frozen `BENCH-FIXED-V1` suite with formal `27/27` result.

This candidate is not published. Hardware power-loss durability is not
promised; process-crash recovery and durable-write configuration are retained.
