# Evidence Entry Template

```text
ID:
Capability:
Product / source:
Version / commit:
User-visible behavior:
Source evidence:
Key types / symbols / call chain:
Persistent state / protocol:
Tests / runtime evidence:
Maturity:
Dependencies and complexity:
Security risk:
Potential value to spool:
Decision:
Time horizon:
Unresolved questions:
```

## Evidence rules

- `Fact` describes directly observed source, documentation, test, or runtime behavior.
- `Interpretation` explains what the evidence likely means.
- `Decision` states what spool should do, using `adopt`, `adapt`, `probe`, `watch`, or `reject`.
- A source path without a commit or version is incomplete unless the source has no external version identity.
- Prompts, code excerpts, and internal identifiers are not copied into this knowledge base.
