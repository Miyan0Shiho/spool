## Architecture Alignment: 2026-09-19

The product is an autonomous agent for real work; coding is its first-stage
delivery domain, not its permanent identity. Product code is independently
implemented, with Claude Code as the primary architectural reference and
DeepSeek Harness as a focused source for autonomous orchestration, persistent
goals, observability, and supporting reliability contracts.

See [`docs/architecture/overview.md`](../architecture/overview.md) for candidate designs.
Design coverage does not promote deferred implementations into P0. Here,
autonomous task orchestration is distinct from frozen research-flow templates
and workflow marketplaces. Background shell processes remain P0; background
agents and multi-agent orchestration do not become P0 merely by sharing the
word "background." RSI remains a long-term product direction with implementation
deferred.

The user subsequently confirmed that the basic coding agent may be the first
external release. Persistent goals, autonomous orchestration, and richer
observability follow in stages. The alternative of requiring all three before
the first release was not adopted. P0 safety, recovery, background commands,
and local audit remain mandatory; see
[`P0 implementation plan`](../architecture/p0-plan.md).
